# Add data to a cohort

An existing cohort is a prerequisite for adding data. If necessary, [create a cohort based on an available schema](../cohorts.md#create-a-cohort) before continuing. The selected schema defines the structure, meaning, and validation rules for the cohort's data.

Data can be added in two ways:

- [Import data through a connector](connectors/index.md). This is the preferred method for larger datasets and recurring updates.
- [Create or edit records manually](manual-patient-management.md). This is useful for individual records and targeted corrections.

Use the guide that matches your task:

1. [Connectors](connectors/index.md): Create a connector from scratch or import an existing definition, and prepare supported input files.
2. [Import data by running a connector](import-data.md): Run a configured connector and review the resulting changes.
3. [Data validation and normalization](input_validation.md): Understand how imported values are converted, validated, and reported.
