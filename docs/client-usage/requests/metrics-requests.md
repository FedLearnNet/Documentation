# Metrics requests

:::note
This page is under construction. A detailed guide with screenshots will be added soon.
:::

A metrics request asks for the local metrics of a completed federated learning run, calculated on your Client's own data. It can be submitted by:

- Any user, if the run's resulting Inference Tool is public.
- Only the user who created the run, otherwise.

Open **Requests → Metrics Requests** to see the list of metrics requests received by your Client. Select a request to review its details, then accept or reject it.

Metrics requests can be approved automatically if a matching access permission sets **Automatic metrics access for** to `All`. See [How permissions decide the outcome](../governance/access-management.md#how-permissions-decide-the-outcome).
