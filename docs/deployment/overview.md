# Welcome
The following view pages guide you through setting up your own
FL-Net **Client** joining the %%%DEPLOYED_PRODUCT_NAME%% network or your own FL-Net based network. 

Please make sure to read at least
- the [Welcome page](../intro/welcome.md)
- the [Solutions page](../intro/solutions.md)
- the [Get started page](../intro/get-started.md)
- the [Graphical overview page](../intro/graphical-overview.md)

This will help you understand **what** you are deploying and **why** you are deploying it, before you start the actual deployment.

Once you've familarized yourself with the concepts, you can start with the deployment:
- [Deploy your Client](deploy-client.md) if you want to join the %%DEPLOYED_PRODUCT_NAME%% network as a data holder (you can also join another FL-Net based network)
- [Deploy your own Platform](deploy-global.md) if you want to run your own FL-Net based network, for example for internal use or for a consortium of institutions.
